# Core Python data structures
I've had a post sitting in draft for months detailing some of the performance characteristics of the [core Python data structures](http://docs.python.org/2.7/library/stdtypes.html).  I'm sure I'll get around to finishing that post one day.  However, if you're just getting started with [Python](http://python.org) or need a refresher on some of the built-in types the [nettuts](http://net.tutsplus.com/) website has a [great article](http://net.tutsplus.com/tutorials/advanced-python-data-structures/) for you.

The article is worth a read for even experienced developers simply for the short discussions on when to use each type.  This is probably second-nature for many developers, but it's always nice to jog your memory on this crucial subject matter.
