# Confusion over Python += operator
I found [this great article](http://emptysquare.net/blog/python-increment-is-weird/) breaking down the [bytecode](http://docs.python.org/2/glossary.html#term-bytecode) that contributes to some of the odd behavior about the `+=` operator in [Python](http://python.org).  The moral of the story is when confused try looking at the [bytecode](http://docs.python.org/2/glossary.html#term-bytecode) for more answers.

Also, I [previously](http://codrspace.com/durden/beware-of-subtle-python-list-semantics/) discussed confusion related to lists and the `+=` operator.  It's worth a quick read if this sort of stuff interests you.
