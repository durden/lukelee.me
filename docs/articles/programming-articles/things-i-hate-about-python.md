# Things I hate about Python
I was surprised while reading this [short somewhat objective Python article](http://wyattbaldwin.com/2014/01/13/what-i-hate-about-python/).  I was surprised because I felt like I had written the article.  I've been developing Python for quite a while now, and I worry I'm too deep to be critical of it.

So, I appreciated how the article mentioned the common complaints about Python and how they didn't bother the author too much.  However, I would have put packaging into the 'things that bother me a little bit more.'
