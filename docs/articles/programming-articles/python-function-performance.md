# Python function performance
[Doug Hellmann](http://www.doughellmann.com) wrote a [great article ](http://www.doughellmann.com/articles/misc/dict-performance/index.html) on why using `dict()` is much slower than the literal `{}` syntax.  It's worth a read, especially if your interested in the performance overhead of Python function calls or the [CPython](http://en.wikipedia.org/wiki/CPython) interpreter in general.
