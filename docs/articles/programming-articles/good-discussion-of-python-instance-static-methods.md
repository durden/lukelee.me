# Good discussion of Python instance/static methods
[This article](http://agiliq.com/blog/2012/06/__new__-python/) is billed as a discussion of what the [__new__](http://docs.python.org/reference/datamodel.html#object.__new__) method in Python does and how to override it.  The article covers this topic with great attention to detail.

However, I actually thought the discussion on some of the subtleties of instance methods and [__new__](http://docs.python.org/reference/datamodel.html#object.__new__) vs. [__init__](http://docs.python.org/reference/datamodel.html#object.__init__) were even more interesting.

This isn't something I haven't read about before.  After all, the [Python data model docs](http://docs.python.org/reference/datamodel.html) discuss a lot of the article's topics in detail.  However, I thought the author did a good job of explaining a familiar topic with an approach just different enough to learn something new.
