# Interesting syntactic sugar
[Python](http://python.org) is a dynamic language that allows you do interesting things, including adding [syntactic sugar](https://en.wikipedia.org/wiki/Syntactic_sugar) to your code.  Often times this 'sugar' leads to *less* readable code in my opinion.  However, it's still interesting to see what people come up with.  For example, here's an [interesting take on regex synactic sugar for Python](http://charlesleifer.com/blog/playing-with-python-magic-methods-to-make-a-nicer-regex-api/).

I think the result is less readable, but it's an interesting use of some advanced techniques including metaclasses and operator overloading.
