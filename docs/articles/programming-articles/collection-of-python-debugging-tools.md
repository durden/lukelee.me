# Collection of Python debugging tools
Here's a [great collection of Python debugging tools](http://blog.ionelmc.ro/2013/06/05/python-debugging-tools/).

The author's list is pretty exhaustive including tools like [GDB](https://www.gnu.org/software/gdb/) and [strace](http://linux.die.net/man/1/strace), which you may have forgotten if you've been working exclusively with Python lately.
