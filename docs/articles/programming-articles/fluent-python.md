# Fluent Python
I started reading the early release version of [Fluent Python](http://shop.oreilly.com/product/0636920032519.do), which is excellent. Hopefully I'll get around to doing a review at some point, but in the meantime this particular quote sticks out:

> Optimization is the altar where maintainability is sacrificed.

It's important to aim for clean code before optimization because the code won't be any cleaner once it's optimized.
