# Look before you code
I think all Python developers should watch the [stop writing classes](http://pyvideo.org/video/880/stop-writing-classes) talk by Jack Diederich from [Pycon](https://us.pycon.org/2012/about/).  This was one of my favorite talks from the conference.

I think his comments on writing your own exception classes is very similar to my rant on [smart python asserts](http://codrspace.com/durden/smart-python-asserts/).  The authors of the language have spent a lot of time designing exceptions, asserts, and all sorts of other stuff.  So think before you code.  Is what your doing really so unique and cutting edge that you need to write your own?
