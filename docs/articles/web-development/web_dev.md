# Web Development

The majority of [my web development portfolio](http://lukelee.net) is hosted on
a [PHP](https://en.wikipedia.org/wiki/PHP) website I wrote while in college.
It is maintained, but not actively developed anymore.

Below you'll find more information about web projects I actively maintain and
older ones that have went off into Internet oblivion.

## Maintained

The website you're viewing right now is powered by
[syte](https://github.com/durden/syte), which is an open-source
[Django](https://www.djangoproject.com/) application that I've contributed to.
My contributions include the markdown powered blogging and JavaScript plugin
controlling the [last.fm](http://last.fm) sidebar.

## RIP

[hack.guides()](https://pskb-prod.herokuapp.com) is an open-source project I
wrote and maintained for a few years for
[Pluralsight](https://www.pluralsight.com).  The project was written using
Flask, Redis, Github API, and hosted on Heroku.  You can see all the source
[on the official github project page](https://github.com/pluralsight/guides-cms).

Codrspace was another blogging platform written in Django with
[Glen Zangirolami](http://www.glenbot.com).  The app used github gists to store
code samples and allowed a full-featured blogging solution customized for
developers.  You can find the code [here](https://github.com/Codrspace/codrspace).

I worked throughout college at [CTSI](http://www.ctsinet.com/Home.aspx) and did
[ASP](https://en.wikipedia.org/wiki/Active_Server_Pages) development for years.
The majority of the sites I developed are not available anymore.  However, I've
maintained a 'portfolio' over the years.

See all my previous unmaintained work at [lukelee.net](http://lukelee.net).
